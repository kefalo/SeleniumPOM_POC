1.Make a project tree, define what libraries will be used at the beginning of the project
2.Create Pages and Tests folders under project structure
3.define conftest, Base_Page classes and methods, declarations
4.once framework is ready for same basic tests and execution, picking up the dummy website against which we will perform the testing
5.map all the objects from the chosen app, create locators, basic methods for the objects
6.update the libraries being used for tests
7.start writing the tests with everything included, allure, markers etc
8.run the tests in headless and non-headless mode, observe the output, logs, reports
9.make debugging and troubleshooting easier - think about improvements
